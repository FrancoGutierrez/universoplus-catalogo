# UniversoPlus - Catálogo Oficial de Moda Curvy & Plus Size

Catálogo web interactivo para boutique de moda curvy con carrito de compras y pedidos automatizados vía WhatsApp.

## 📱 WhatsApp de Pedidos
- **Número oficial:** `+51 944 524 476` (51944524476)

## ✨ Características
- **Experiencia 100% para cliente final:** Diseño elegante y responsive optimizado para compras desde celulares (WhatsApp, Instagram, etc.).
- **Selector de tallas en cada prenda:** XL, XXL, 1X, 2X, 3X, etc.
- **Carrito de compras lateral (Drawer):** Selección de cantidades, cálculo de totales en Soles (S/.) y personalización con nombre del cliente.
- **Generación de pedidos a WhatsApp:** Desglose automático de prendas seleccionadas, tallas, cantidades, subtotales y foto de referencia.
- **Buscador y filtros por categoría:** Conjuntos, Lencería, Vestidos, Pijamas, Deportivo, Accesorios.
- **Panel de control discreto:** Para modificar márgenes, tipo de cambio o número de WhatsApp sin que el cliente lo vea.
